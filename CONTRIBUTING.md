# Contribuer à Gestion Commerciale

Merci de votre intérêt pour ce projet.

## Comment contribuer

1. Forkez le dépôt.
2. Créez une branche pour votre modification.
3. Effectuez vos changements.
4. Ouvrez une pull request avec une description claire.

## Standards de code

- écrivez un code propre et lisible
- ajoutez des tests si possible
- vérifiez que la CI passe avant de proposer une PR
